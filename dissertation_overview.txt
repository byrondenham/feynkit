======================================================================
  §3  Three parametrisations
======================================================================

── Schwinger parametrisation  (integration over R_{>0}^E) ────────────
  Prefactor  : exp(epsilon*gamma_E)/(gamma(nu1)*gamma(nu2)*gamma(nu3))
  Parameters : [alpha_1, alpha_2, alpha_3]   (Schwinger α variables)
  Measure    : alpha_1**(nu1 - 1)*alpha_2**(nu2 - 1)*alpha_3**(nu3 - 1)

── Feynman parametrisation  (simplex constraint) ─────────────────────
  Prefactor  : exp(epsilon*gamma_E)*gamma(-D/2 + nu1 + nu2 + nu3)/(gamma(nu1)*gamma(nu2)*gamma(nu3))
  Parameters : [a_1, a_2, a_3]   (Feynman x variables, Σxᵢ = 1)
  Constraints: [Eq(a_1 + a_2 + a_3, 1)]

── Lee–Pomeransky parametrisation  (u ∈ R_{>0}^E, no constraint) ─────
  Prefactor  : exp(epsilon*gamma_E)*gamma(D/2)/(gamma(nu1)*gamma(nu2)*gamma(nu3)*gamma(D - nu1 - nu2 - nu3))
  Parameters : [u_1, u_2, u_3]   (LP u variables)
  The integrand is u^β · G^{-β₀} with G = U + F.

======================================================================
  §8  Symmetry pairs  — transformation identities
======================================================================

── Definition ────────────────────────────────────────────────────────
  A symmetry pair (M, t, P) satisfies  T·A = A·Π_P
  where T = [[1, 0ᵀ], [t, M]] ∈ GL_{n+1}(ℤ)  and  Π_P is a column permutation.
  It gives the integral identity:
    I_A(β, z) = I_A(T β, z_P)
  Unimodular maps (|det M| = 1) are polytope automorphisms;
  non-unimodular maps (|det M| > 1) are finite-index self-embeddings.

── Triangle LP symmetry pairs  (48 total) ────────────────────────────
  Unimodular (|det| = 1): 48
  Finite-index (|det| > 1): 0

  First unimodular pair:
    M =
⎡1  0  0⎤
⎢       ⎥

⎢       ⎥
⎣0  0  1⎦
    t = [0, 0, 0]
    column permutation P = (0, 1, 2, 3, 4, 5)
    Integral identity: I_A(β, z) = I_A(T·β, z_P)

  §10  Polytope equivalence

── Unimodular equivalence  (Liu–Cai, arXiv:2506.23846) ───────────────
  Tests: ∃ U ∈ GL_n(ℤ), t ∈ ℤⁿ  such that  {Uv + t} = vertices of Q.
  Unimodular equivalence ⟹ GKZ systems have identical analytic structure.

  Triangle (labelling A) ↔ Triangle (labelling B): True
  Witness U =
⎡1  0  0⎤
⎢       ⎥
⎢0  1  0⎥
⎢       ⎥
⎣0  0  1⎦
  Translation t = None

  Massless triangle ↔ Massive triangle: False

── Affine equivalence  (rational maps, hull vertices only) ───────────
  Tests: ∃ M ∈ GL_n(ℚ), t ∈ ℚⁿ  with  M·vert(P) + t = vert(Q).
  Weaker than unimodular; captures same combinatorial shape up to scaling.

  Massless triangle ↔ itself (rel): True, det = 1

── Point-configuration equivalence  (stricter GKZ condition) ─────────
  Tests the same map on ALL A-columns, not just hull vertices.
  This is the correct condition for GKZ-system isomorphism.

  Triangle LP ↔ Triple-K (all columns): True
  det M = 2

  §11  Finite-index map  (det ≠ ±1 integer maps)
======================================================================

── Concept ───────────────────────────────────────────────────────────
  An integer affine map x ↦ Mx + t with M ∈ GL_n(ℤ) but |det M| > 1.
  Such a map takes every source point to a target point, but the image
  lattice has index |det M| in the target lattice.
  For GKZ systems, a det = k map implies the holonomic ranks differ by k.

  §13  Landau singularity analysis

── Method: edge-part of the principal A-determinant ──────────────────
  The Landau singularities of I_A are encoded in the principal
  A-determinant E_A.  The edge-part E_A^(1) is the product over
  all edges of the discriminant of G restricted to each edge.

    L = (s12 + s13)**2*(s12 + s23)**2*(s13 + s23)**2
  Landau surfaces (irreducible factors):
    [0]  s12 + s13 = 0
    [1]  s12 + s23 = 0

  Interpretation: each surface L_k = 0 is a threshold in the
  external kinematics where the integral develops a leading singularity.
